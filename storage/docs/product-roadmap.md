# Product Roadmap Notes

The first useful products for this lab are:

1. A private business assistant LoRA for a single workflow.
2. A niche creator style/model pack for repeatable content.
3. A local knowledge worker copilot for docs, research, and drafting.

The MVP should focus on:

- fast local iteration on a Mac
- frozen eval sets
- measurable gains over baseline
- synthetic data only from good outputs
- keeping the system small enough to inspect by hand
